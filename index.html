🤔 How Does It Work?

Think of it like sending a locked package through the mail. Here's what happens every time you use recover-secrets:

  1. You provide a secret (like a password or API key)
  2. recover-secrets locks it using your personal encryption key
  3. The encrypted secret goes to GitHub, looking like random characters
  4. GitHub uses it without ever seeing what's inside
  5. Your secret stays safe even if someone views the logs
